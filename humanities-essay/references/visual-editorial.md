# 视觉编辑｜不把单图做成同款滤镜

## 默认媒介策略

当用户指定抖音**单张图片＋音乐＋长简介**时，先交付**单张图片方案**；不擅自拆轮播或给精确音乐“卡点”。图承载首屏意象，文字完成叙事，音乐是氛围。没有源音频分析，不声称音符与某一段阅读能够同步。

## 视觉概念的选择

先从文章抽取：*核心问题*、*最可视化的史料物件*、*最强的人物张力*、*情绪温度*、*历史时期*。再在互不相同的视觉路线中选 **一条**：

| 路线 | 适合 | 易犯错误 |
|---|---|---|
| 人物速写/漫画特写 | 内心复杂、表情冲突 | 只追求帅气，丢掉人物年龄与时代 |
| 极简版画/木刻 | 具有可读形状的单物件 | 过度怀旧导致千篇一律 |
| 文献意象/文字肌理 | 一句诗、一段史书、一封书信 | 伪造“原件”、制作不可读的假汉字 |
| 剧场式色块/剪影 | 命运与身体动作 | 过度戏剧化、把推测镜头当史实 |
| 空间与留白 | 地点、失去、不可抵达 | 主体过小导致手机端识别困难 |
| 现代编辑艺术/抽象拼贴 | 哲学性或版本冲突 | 元素堆砌，隐喻需靠文字解释 |
| 清冷生活绘本 | 诗词、日常、友谊 | 把历史困顿拍成浪漫度假 |

同一系列允许不同色彩与媒材；只保留较低优先级的系列识别元素（例如图像比例、页面边距、可选角标），不要强制统一“黑金古城+大字”。

## 单图交付契约

1. 一句话视觉命题（不复述全文）。
2. 主体/空间/光线/材质/主色与对比色；说明不应该出现的元素。
3. **避免历史误导**：具体建筑、官帽、军备无法核实时避免“考据复原”字样；历史绘画与戏剧化想象需识别为艺术表现。
4. **文案排版可选**：原图尽量无字，需加字则在后期人工排版与校验，避免图像生成乱码。
5. 手机缩略图检查：中心意象 1 秒可辨，裁切后信息不丢失，画面留白有意图。
6. 使用音乐前检查版权授权及平台曲库状态；不承诺音量百分比、时长与传播结果。

用户只要文案时，不主动生成封面；用户要图片时，给图片或清楚写明当前无法生成的限制。
