# Humanities Essay v3.5.1｜以人为中心的跨题材叙事工作流

## 使命

**让人的处境被认真理解：历史是入口之一，私人生活、技术变化、普通人的经验也同样值得书写。**

通过可靠材料、诚实的亲历与准确语言，交付有知识增量、情感力量和原创视角的作品。作者判断可以鲜明，但个人体验、历史记载和社会推断不可彼此冒充。**好听不是证据；悲伤不是论证；高分不是爆款保证。**

**史实层决定能不能说，传播层决定会不会有人读。**两者都是交付标准：通过事实门禁只是及格；一篇处处留余地、没有人读完的文章，同样没有完成任务。审慎要靠核实和文末注来保证，不要靠稀释正文的情绪。传播层规则见 [传播层](references/reader-engagement.md)。

本 Skill 综合用户提供的 13 篇人文长文、先前秦始皇案例、humanities-essay v2.0.0 及 Codex 提供的 historical-narrative-shortvideo 工作流；学习可迁移机制，不复刻特定作者的人设、专属意象、履历或连续句式。用户样文属于分析语料，**不是事实来源**。

## 0｜先识别请求；不要无故扩大交付

| 请求 | 应交付什么 | 不要多做什么 |
|---|---|---|
| 原创成稿 | 满足主题、字数、语体、渠道的完整正文 | 用户只要正文时不附内部表格和教程 |
| 选题或立意研究 | 可比较的切口、依据、反证和取舍 | 未获请求不先写数篇全文 |
| 拆解样文 | 文本可观察的结构、技巧、引用风险；传播推论另标 | 无后台数据不宣布“爆火原因已证实” |
| 史实复核 | 逐项判定并指出可替代句与来源 | 不静默重写作者的价值立场 |
| 私人随笔／时代观察 | 以真实体验为中心，区分“我经历了什么／我的解释／外部普遍论断” | 不编造自述、不强行插历史人物或哲学典故 |
| 已认可稿的局部精修 | 尊重作者冻结区、保留语体，只处理明确问题与必要连带 | 不为了分数、句号数量、华丽感反复生成新稿 |
| 改稿 | 先定位最大缺陷，再做最小充分修改 | 不借机把全文换成标准 AI 腔调 |
| 发布组合 | 文案及用户指定的封面、配乐方向、分镜或口播 | 单图配乐长简介不得自动拆为轮播 |

优先从上下文推断主题、媒介和语体；只有不可逆的重大歧义才询问一个关键问题。用户指定“只输出正文”、精确字数或格式时优先遵守。不确定的事实不能通过虚构来补全。

## 1｜确定命题：先让材料与立意互相检验

写前准备至少两条**性质不同**的候选立意（内部可简记），选证据最能承受、对读者最有新意的一条。可用以下问题寻找矛盾：

- **被遮蔽的侧面**：熟悉的称谓、教科书叙事、省略了哪个人或哪个代价？
- **彼此冲突的价值**：信义与生存、理想与后果、制度与个人、才华与时运、复仇与宽恕；不必都是“孤独天才”。
- **反证**：有没有一条重要材料会削弱我的漂亮解释？若有，必须容纳它或缩小主张。
- **读者增量**：读完究竟多知道一个什么事实、多理解一个什么难题？
- **读者为什么停下**（传播层，必答）：①**一句话测试**：能否用一句不提朝代、官职、史书的话说清这篇讲什么？②**母题**：冲突是否落在亲子、夫妻、朋友、上下级、怀才不遇、回不去的故乡等普通人也经历过的处境上？③**熟悉度**：第二梯队人物只取一个强情感切口，不写生平。“X 为什么 Y”这种史学题可以出现在文中，但不能做题眼。详见 [传播层 §1](references/reader-engagement.md)。

**现代个人随笔额外确认**：题眼是否源自作者认可的经历／情绪？只把已提供或明确确认的行为与体验写成第一人称；推测“可能有这种感觉”不能改成“我曾经这样做”。不要为获得共鸣发明通宵、失眠、对话、旅行或他人回应。详见 [亲历与时代写作](references/first-person-and-era-essays.md) 及 [作者经历台账](assets/author-experience-ledger.md)。

可用一句内部工作句明确命题：“不只是在写 X 的 Y，更在写 A 与 B 如何相撞。”但**不把这句话直接当成每篇文章的开头**。题目材料薄弱时缩小问题，不为凑三到六个场景制造情节。

## 2｜证据台账先于抒情

重要事实和引文至少记下：**主张—来源定位—材料类型—可用表述—争议／反证—核查状态**。完整做法见 [事实核查](references/evidence-protocol.md)，可直接复用 [台账模板](assets/evidence-ledger.md)。

- **F 文献记载**：准确表述为“某文献记载”，不等于自动证实事情真实发生。
- **I 作者解释**：事实支持的合理阐释，保留不同解释的可能。
- **A 改编版本**：文学、小说、影视、戏剧，必须给出具体版本，不能偷换为史料。
- **R 明示重构**：作者为了表现体验而添加的画面／心理，不得伪装现场纪实或历史引语。
- **D 存争议**：记清争议双方与资料限制；正文使用限定表达。
- **U 待核**：没有可追溯依据，不可冒充可发表事实。

对现代随笔，不把“我觉得”当作可验证的统计事实：**P 作者亲述**（仅限对话提供／作者确认）、**O 可观察外部事实**（应核源）、**H 解释或假说**（明确范围）、**X 缺证待确认**（不得冒充亲历）。这组创作标签是文内工作法，不替换历史资料 F/I/A/R/D/U 标签，也不要求把标签写进正文。

优先核对原文、引文上下文、编年、数字、身份、死亡原因与重大因果链。用户给的文章是研究对象，不是替代文献的证据。可查资料不足时，缩小到可支持的论题，或交付显式待核稿；不得写“已验证”。

**一票阻断**：捏造引文／个人经历、把影视桥段写成正史、核心年代或数字有未解决错误、隐藏足以推翻主张的关键反证、无证据断言古人的内心、将争议解释冒充定论。

**处理反证 ≠ 把反证写进正文。**核实是必须的；但正文只保留一条推进观点的反证，免责式限定（“史书没有记载……”“不能假装……”“既不能……也不能……”）放到文末一行注或置顶评论，正文最多 1 处。放进文末注不算隐藏，删掉才算。见 [传播层 §4](references/reader-engagement.md)。

## 3｜选“叙事发动机”，不强制套英雄传记

按材料决定主结构，必要时局部混合，见 [七类结构](references/story-architectures.md)：

1. **字句显微镜**：拆一个词、动作、停顿或语气如何改变全篇。
2. **版本比较**：同一故事在不同年代、体裁中的改写和价值转向。
3. **对照审判**：同类人物的动机、手段、代价和反例。
4. **意象考古**：某件物、空间或意象在不同文本中的变义。
5. **时间回声**：年表、重逢、相同数字或被改变的称呼。
6. **真实观察／元写作**：用户提供的亲历或可诚实描述的阅读研究现场。
7. **时代中的个人处境**：一个真实但尚未得到解释的当代矛盾（科技、工作、成长、AI 与人性），把问题说得更准确，而不是强行解决；不必硬塞历史人物，也不把个人经历写成社会统计。

历史**人物传记**可用“熟悉标签 → 人之处境 → 关键场景 → 反向材料 → 制度／时代后果 → 遗产／回响”；这是可选路线，不是所有题材必经序列。诗词与意象篇不必编造人物创伤，也不必强行扩大到文明命运。

## 4｜场景是论据，不是装饰

对于情节型长文，优选 **3–6 个功能不同且可靠的场景**；若一句诗足够承重，两个场景也可以。用 [场景台账与转场](references/narrative-toolkit.md) 标记每个片段的来源、冲突、具体锚点、反证与叙事功能。

- 要有**动作／物件／地点／一句可靠的话**，而不只是“他很痛苦”。
- 场景必须推进理解：展示选择、限制、转折、代价或歧义。
- “先讲小动作、再讲大制度”是一种尺度变化，不自动成立历史因果。
- **史料写过的就写成镜头**：记载中的动作、言语、物件、数字、在场者可以直接写成场景（史书写“泣数行下”，就可以写他当众流泪）。不得添加史料没有的动作细节、对白、天气和确定的内心（如凭空写“紧握佩剑”“望向夜空”）。推测心理时要明说是推测，一篇最多一两处。见 [传播层 §3](references/reader-engagement.md)。
- **定一个情绪峰值**：写前确定全文最高的那个场景；峰值段落只写场景，后面不紧跟纠偏或学术限定。
- **前三行**：一个人、一个有依据的动作或一句话、一个反差。不要以问题、背景或万能句式开头。
- 让人物复杂：被伤害的人也能造成伤害；宏伟事业也可能带来沉重后果。

**段落运动**可参考“看见事情 → 发现异常 → 重新解释 → 下个未解问题”；不要求每段四拍，更不需要固定每 300 字插一条金句。

## 5｜语言编辑：热度来自准确，不来自古风词密度

1. 先用清晰的动词与名词搭骨架，再决定哪里值得比喻。
2. **默认流水句**（作者经历台账未指定节奏偏好时适用；台账选了说书体或短句排比，以台账为准）：一条动作链写成一句，用逗号连缀；句号只放在意思说完或情绪转折处。单独成行的短句每篇只留 3–5 个落点，判断短句（“这是萧何。”）不单独成行，要挂在叙事后面一口气说完；对仗收束一篇最多一次。适当使用连接词、语气词和破折号。长句累积张力，短句用于落点；空白是有意义的沉默，不是用省略号遮盖缺失转折。详见 [自然语流 §0](references/rhythm-and-line-editing.md)。
3. 宏大判断应由具体细节挣得；口语、轻微幽默可以调温，但不能拿灾难或受害者取乐。
4. 贯穿意象在末尾可以改变意义；回环不等于复制首句。
5. “我想”“或许”用于真实不确定，不是给任意断言涂上谦逊外衣。作者可以有明确判断：复杂性靠展示材料体现，不靠每句话都留余地。正文对冲超标时，用 `python scripts/check_hedges.py <稿件.txt>` 检查。
6. 不编造作者的求学、旅行、恋爱、失业、父母等经历；没有真实私人现场就用材料观察或阅读现场。**但作者在 [经历台账](assets/author-experience-ledger.md) 中确认过的真实经历和账号口吻，应当主动用来做入口或类比**：读者点赞的有一半是“这个人”。
7. **结尾把情绪交给读者**：落到读者的处境，或者让开头的意象重新出现并改变意义。不要以史实收尾（“某年去世，谥为××”），也不要说教。
8. 不照搬样文的独特比喻、“祖龙眼睛”式专属画面、口头禅或高辨识度句群。
9. **三层分评，不能以标点计数代替文学审稿**：①规范正确（标点、语法、搭配、指代）；②语流自然（连续动作／因果是否被无效切断）；③文学表现（停顿是否带来新信息、认知或情绪转向）。完整协议见 [自然语流与行文编辑](references/rhythm-and-line-editing.md)。
10. 句号、逗号、分号都不是优化 KPI；禁止机械地以逗号或分号替换句号。但“不当 KPI”不等于“不处理”：句号落在判断上、一句一行连续出现时，读者会觉得正式、有距离、像 AI，这时必须**重新说一遍**（饭桌上讲给朋友听的说法），而不是换标点。`check_hedges.py` 会提示句长和判断短句。
11. 叙事节奏可以随经历、信息涌入、觉察而变化，但**“连贯→急促→留白”只是一个案例的可选路径**，不是所有主题的通用结构。

按需阅读 [文学表达](references/rhetorical-craft.md)。目标是**作者有立场、证据有阻力、人物有复杂性、结尾有余韵**。

## 6｜不同载体，先守住媒介边界

- **单张图片＋配乐＋长简介**：首句承担信息流钩子；图片承担视觉锚点；音乐承担氛围；长文承担完整叙事。**不拆成十几屏**。
- **多图轮播**：逐屏确立一个阅读任务，图文分工，避免把长文机械切段。
- **剪辑视频／动态字幕**：按镜头、动作、阅读／观看节奏分 beats，必要时给时间轴。
- **口播稿**：按实际朗读速度检查句长、专名、停顿、时长，不从字数虚构精确秒数。
- **公众号与小红书**：遵守用户指定字数和排版；需要时提供来源说明、摘要和标题。

完整细则见 [发布渠道手册](references/platform-playbooks.md)。动态变化的简介限制、素材版权、平台推荐机制要实查；没有后台数据只能提出传播假设，不宣称因果确定。

## 7｜逆向编辑与交付

**先硬门禁，后软评分。**任何关键事实阻断项未解决，只能标为草稿／待核，不能标“可发表”。通过硬门禁后，再按 [质量评分](references/editorial-qa.md) 检查：

- 立意的辨识度；场景密度与功能；人物复杂度；史实诚实度；情绪递进；语言准确度；结尾回响；媒介适配。
- 去名测试：换个人名仍能成立吗？若是，可能写成套模版。
- 去装饰测试：删掉最美的句子，事实和论证还成立吗？
- 敌对读者测试：最强反证有没有核实并处理？（处理的方式可以是正文一句话，也可以是文末注，不必在正文里逐条自辩。）
- **划走测试**：只读前三行，陌生读者会不会继续往下读？
- **一句话测试**：不提史书和朝代，能不能说清这篇写的是什么？
- **峰值测试**：单独读峰值段落，能不能让人动容？
- **对冲测试**：运行 `scripts/check_hedges.py`，正文免责句不超过 1 处。
- 静音测试：去掉音乐图片，正文还有阅读价值吗？

**改稿优先修一个最大的根因**，一并处理必要连带问题，避免无关重写。只有作者明确批准的改动才能执行；“只读审稿”“不要结构性修改”“结尾锁定”是不同等级的边界。用 [修订治理与停笔规则](references/revision-governance.md) 和 [变更记录](assets/revision-decision-log.md) 保存修改范围、保留内容、验证结果与剩余风险。

**停止条件**：题眼稳定，作者确认第一人称经历与心理表述，硬性事实／语言错误已修，媒介满足要求，关键句与结尾符合保护线，继续修改只剩不同文风的主观偏好时，转为 `AUTHOR_READY` 并停止主动制造 Vn。`AUTHOR_READY` 不等于已经发布或质量可预测。

创作用户只要正文：交付完整成稿。用户要“发表核查版”：正文后附简短来源／争议说明。缺乏来源时只说明未核处，绝不伪造已经完成的检验。质量分数是编辑辅助，不预测流量。

## 8｜真实跨题材创作实践新增的约束

- **不限历史的“一篇一个问题”。** 项羽写武力边界、刘邦写胜利代价、韩信写才能与权位、李斯写位置与退出、苏轼写受限生活里的感受力。示例只说明方法，不能直接照抄它们的表达、评价与意象；参考 [五篇案例复盘](references/five-case-study.md)。
- **先判定本次要做什么。** 只审稿不改稿；获准修改则记录允许修改的句子及受影响的必要连带处。用户锁定的意象、句子与结构先作为不可改项，除非有重大的事实错误或明确解除保护。
- **把“为什么能赢”与“赢后付出什么”分开。** 开头入口问题和真正题眼可能不同；场景应服务题眼。不要为制造整齐系列对照，把人物写成教训。
- **单张图片＋音乐＋长简介是独立产品形态。** 默认只给一张视觉方案，避免擅自改成七图；封面风格按本篇题材选择，而非把全系列都做成同一种水墨城门。详见 [视觉编辑](references/visual-editorial.md)。音乐只应与整体阅读情绪相容，不能假定观众会恰好在某个乐句读到结尾。
- **发布前真实计数。** 明确区分正文、标题、话题标签、空行。可以运行 `python scripts/check_length.py <稿件.txt> --min 2500 --max 3000` 做保守预检；平台实际输入框仍是最终口径。
- **数据复盘不能装作因果实验。** 记录发布年龄、封面类型、播放、展开、赞、评、藏、分享的真实分母；短样本只产生假说，不宣告封面/BGM保证爆款。方法见 [发布复盘](references/measurement.md)。公开仓库不要附带账号后台截图或未经允许的受众数据。
- **第六次真实创作的抽象复盘**：当代 AI 随笔显示“选择变多／理解跟不上／自我追加任务”可以成为有机的题眼；多版本改稿同时暴露过度断句、无效解释、过度平滑、持续改写作者认可文本的风险。只使用经匿名化的方法，不在公共 Skill 仓库放作者的私密原稿和对话。参照 [第六案例的方法复盘](references/sixth-case-lessons.md)。
- **v3.3 传播层复盘**：在一个账号的 11 篇里，首篇（第一梯队人物、素材自带高潮）获赞约 1000+，后续第二梯队人物和史学题切口多为 20+；对标的 5W+ 文章都具备情感母题、场景开头、鲜明作者和交给读者的结尾。主要失误是正文里堆积“既不能……也不能……”式免责，连影视解读也在做史料免责。由此新增 [传播层](references/reader-engagement.md) 和对冲检查脚本。这只是没有后台数据的假设，需要用 [发布复盘](references/measurement.md) 来验证。
- **状态显式区分。** 结构校验 PASS ≠ 史实已核验 ≠ 独立审稿完成 ≠ 目标模型回归通过 ≠ 发布成功。交付时分别陈述。
