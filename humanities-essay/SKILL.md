# Humanities Essay v3.1｜证据驱动的人文叙事工作流

## 使命

**让熟悉的历史与文学重新可见，而不是把现成的人物塞进流量公式。**

通过可靠事实、不同版本、文本细读和准确文学表达，交付有知识增量、情感力量、原创视角的作品。作者的判断可以鲜明，历史的边界必须清楚。**好听不是证据；悲伤不是论证；高分不是爆款保证。**

本 Skill 综合用户提供的 13 篇人文长文、先前秦始皇案例、humanities-essay v2.0.0 及 Codex 提供的 historical-narrative-shortvideo 工作流；学习可迁移机制，不复刻特定作者的人设、专属意象、履历或连续句式。用户样文属于分析语料，**不是事实来源**。

## 0｜先识别请求；不要无故扩大交付

| 请求 | 应交付什么 | 不要多做什么 |
|---|---|---|
| 原创成稿 | 满足主题、字数、语体、渠道的完整正文 | 用户只要正文时不附内部表格和教程 |
| 选题或立意研究 | 可比较的切口、依据、反证和取舍 | 未获请求不先写数篇全文 |
| 拆解样文 | 文本可观察的结构、技巧、引用风险；传播推论另标 | 无后台数据不宣布“爆火原因已证实” |
| 史实复核 | 逐项判定并指出可替代句与来源 | 不静默重写作者的价值立场 |
| 改稿 | 先定位最大缺陷，再做最小充分修改 | 不借机把全文换成标准 AI 腔调 |
| 发布组合 | 文案及用户指定的封面、配乐方向、分镜或口播 | 单图配乐长简介不得自动拆为轮播 |

优先从上下文推断主题、媒介和语体；只有不可逆的重大歧义才询问一个关键问题。用户指定“只输出正文”、精确字数或格式时优先遵守。不确定的事实不能通过虚构来补全。

## 1｜确定命题：先让材料与立意互相检验

写前准备至少两条**性质不同**的候选立意（内部可简记），选证据最能承受、对读者最有新意的一条。可用以下问题寻找矛盾：

- **被遮蔽的侧面**：熟悉的称谓、教科书叙事、省略了哪个人或哪个代价？
- **彼此冲突的价值**：信义与生存、理想与后果、制度与个人、才华与时运、复仇与宽恕；不必都是“孤独天才”。
- **反证**：有没有一条重要材料会削弱我的漂亮解释？若有，必须容纳它或缩小主张。
- **读者增量**：读完究竟多知道一个什么事实、多理解一个什么难题？

可用一句内部工作句明确命题：“不只是在写 X 的 Y，更在写 A 与 B 如何相撞。”但**不把这句话直接当成每篇文章的开头**。题目材料薄弱时缩小问题，不为凑三到六个场景制造情节。

## 2｜证据台账先于抒情

重要事实和引文至少记下：**主张—来源定位—材料类型—可用表述—争议／反证—核查状态**。完整做法见 [事实核查](references/evidence-protocol.md)，可直接复用 [台账模板](assets/evidence-ledger.md)。

- **F 文献记载**：准确表述为“某文献记载”，不等于自动证实事情真实发生。
- **I 作者解释**：事实支持的合理阐释，保留不同解释的可能。
- **A 改编版本**：文学、小说、影视、戏剧，必须给出具体版本，不能偷换为史料。
- **R 明示重构**：作者为了表现体验而添加的画面／心理，不得伪装现场纪实或历史引语。
- **D 存争议**：记清争议双方与资料限制；正文使用限定表达。
- **U 待核**：没有可追溯依据，不可冒充可发表事实。

优先核对原文、引文上下文、编年、数字、身份、死亡原因与重大因果链。用户给的文章是研究对象，不是替代文献的证据。可查资料不足时，缩小到可支持的论题，或交付显式待核稿；不得写“已验证”。

**一票阻断**：捏造引文／个人经历、把影视桥段写成正史、核心年代或数字有未解决错误、隐藏足以推翻主张的关键反证、无证据断言古人的内心、将争议解释冒充定论。

## 3｜选“叙事发动机”，不强制套英雄传记

按材料决定主结构，必要时局部混合，见 [六类结构](references/story-architectures.md)：

1. **字句显微镜**：拆一个词、动作、停顿或语气如何改变全篇。
2. **版本比较**：同一故事在不同年代、体裁中的改写和价值转向。
3. **对照审判**：同类人物的动机、手段、代价和反例。
4. **意象考古**：某件物、空间或意象在不同文本中的变义。
5. **时间回声**：年表、重逢、相同数字或被改变的称呼。
6. **真实观察／元写作**：用户提供的亲历或可诚实描述的阅读研究现场。

历史**人物传记**可用“熟悉标签 → 人之处境 → 关键场景 → 反向材料 → 制度／时代后果 → 遗产／回响”；这是可选路线，不是所有题材必经序列。诗词与意象篇不必编造人物创伤，也不必强行扩大到文明命运。

## 4｜场景是论据，不是装饰

对于情节型长文，优选 **3–6 个功能不同且可靠的场景**；若一句诗足够承重，两个场景也可以。用 [场景台账与转场](references/narrative-toolkit.md) 标记每个片段的来源、冲突、具体锚点、反证与叙事功能。

- 要有**动作／物件／地点／一句可靠的话**，而不只是“他很痛苦”。
- 场景必须推进理解：展示选择、限制、转折、代价或歧义。
- “先讲小动作、再讲大制度”是一种尺度变化，不自动成立历史因果。
- 不凭空加“流泪、沉默许久、紧握佩剑、望向夜空”等电影化镜头。
- 让人物复杂：被伤害的人也能造成伤害；宏伟事业也可能带来沉重后果。

**段落运动**可参考“看见事情 → 发现异常 → 重新解释 → 下个未解问题”；不要求每段四拍，更不需要固定每 300 字插一条金句。

## 5｜语言编辑：热度来自准确，不来自古风词密度

1. 先用清晰的动词与名词搭骨架，再决定哪里值得比喻。
2. 长句累积张力，短句用于落点；空白是有意义的沉默，不是用省略号遮盖缺失转折。
3. 宏大判断应由具体细节挣得；口语、轻微幽默可以调温，但不能拿灾难或受害者取乐。
4. 贯穿意象在末尾可以改变意义；回环不等于复制首句。
5. “我想”“或许”用于真实不确定，不是给任意断言涂上谦逊外衣。
6. 不编造作者的求学、旅行、恋爱、失业、父母等经历；没有真实私人现场就用材料观察。
7. 不照搬样文的独特比喻、“祖龙眼睛”式专属画面、口头禅或高辨识度句群。

按需阅读 [文学表达](references/rhetorical-craft.md)。目标是**作者有立场、证据有阻力、人物有复杂性、结尾有余韵**。

## 6｜不同载体，先守住媒介边界

- **单张图片＋配乐＋长简介**：首句承担信息流钩子；图片承担视觉锚点；音乐承担氛围；长文承担完整叙事。**不拆成十几屏**。
- **多图轮播**：逐屏确立一个阅读任务，图文分工，避免把长文机械切段。
- **剪辑视频／动态字幕**：按镜头、动作、阅读／观看节奏分 beats，必要时给时间轴。
- **口播稿**：按实际朗读速度检查句长、专名、停顿、时长，不从字数虚构精确秒数。
- **公众号与小红书**：遵守用户指定字数和排版；需要时提供来源说明、摘要和标题。

完整细则见 [发布渠道手册](references/platform-playbooks.md)。动态变化的简介限制、素材版权、平台推荐机制要实查；没有后台数据只能提出传播假设，不宣称因果确定。

## 7｜逆向编辑与交付

**先硬门禁，后软评分。**任何关键事实阻断项未解决，只能标为草稿／待核，不能标“可发表”。通过硬门禁后，再按 [质量评分](references/editorial-qa.md) 检查：

- 立意的辨识度；场景密度与功能；人物复杂度；史实诚实度；情绪递进；语言准确度；结尾回响；媒介适配。
- 去名测试：换个人名仍能成立吗？若是，可能写成套模版。
- 去装饰测试：删掉最美的句子，事实和论证还成立吗？
- 敌对读者测试：最强反证有没有正面处理？
- 静音测试：去掉音乐图片，正文还有阅读价值吗？

**改稿优先修一个最大的根因**，一并处理必要连带问题，避免无关重写。

创作用户只要正文：交付完整成稿。用户要“发表核查版”：正文后附简短来源／争议说明。缺乏来源时只说明未核处，绝不伪造已经完成的检验。质量分数是编辑辅助，不预测流量。

## 8｜五篇真实创作实践后新增的约束

- **一篇一个问题，而非一种人物模板。** 项羽写武力边界、刘邦写胜利代价、韩信写才能与权位、李斯写位置与退出、苏轼写受限生活里的感受力。示例只说明方法，不能直接照抄它们的表达、评价与意象；参考 [五篇案例复盘](references/five-case-study.md)。
- **先判定本次要做什么。** 只审稿不改稿；获准修改则记录允许修改的句子及受影响的必要连带处。用户锁定的意象、句子与结构先作为不可改项，除非有重大的事实错误或明确解除保护。
- **把“为什么能赢”与“赢后付出什么”分开。** 开头入口问题和真正题眼可能不同；场景应服务题眼。不要为制造整齐系列对照，把人物写成教训。
- **单张图片＋音乐＋长简介是独立产品形态。** 默认只给一张视觉方案，避免擅自改成七图；封面风格按本篇题材选择，而非把全系列都做成同一种水墨城门。详见 [视觉编辑](references/visual-editorial.md)。音乐只应与整体阅读情绪相容，不能假定观众会恰好在某个乐句读到结尾。
- **发布前真实计数。** 明确区分正文、标题、话题标签、空行。可以运行 `python scripts/check_length.py <稿件.txt> --min 2500 --max 3000` 做保守预检；平台实际输入框仍是最终口径。
- **数据复盘不能装作因果实验。** 记录发布年龄、封面类型、播放、展开、赞、评、藏、分享的真实分母；短样本只产生假说，不宣告封面/BGM保证爆款。方法见 [发布复盘](references/measurement.md)。公开仓库不要附带账号后台截图或未经允许的受众数据。
- **状态显式区分。** 结构校验 PASS ≠ 史实已核验 ≠ 独立审稿完成 ≠ 目标模型回归通过 ≠ 发布成功。交付时分别陈述。
