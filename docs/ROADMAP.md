# Roadmap

## 当前：v3.2.0

- 从五篇历史人物志延展至当代观察、科技与人性、真实第一人称随笔，保持题材开放。
- 对真实经历 P、可查事实 O、解释 H、待确认 X 分轨；历史 F/I/A/R/D/U 继续沿用。
- 建立规范／语流／表现力三层语言审稿，不用句号数、句长或“AI腔”标签替代判断。
- 约束多轮改稿：权限识别、锁定内容、最小修改、作者认可后的停笔。
- 增加匿名第六案例经验、现代案例的文档级回归设计；不包含原始私人文章。

## 后续候选（未承诺）

- 独立评审者对至少 20 个跨题材任务进行盲评，记录全文、反例、拒绝造假行为及一致性。
- 根据作者许可建立匿名改稿 A/B 测试，不以标点计数或单次流量代替质量。
- 支持持续改进的自愿数据授权与版本回归审查。

不提供自动刷量、自动伪评论、未经授权素材抓取或伪造私人经历功能。
