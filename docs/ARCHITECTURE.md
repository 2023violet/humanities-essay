# Architecture / 技能架构

`humanities-essay` 是**声明式技能**，不是调用语言模型的 SDK。唯一入口是 `humanities-essay/SKILL.md`；细则经 references 按需加载，assets 仅是可填写模板，scripts 仅做本地确定性预检。

```text
用户请求 → 识别模式 → 立意及反证 → 史料台账 → 叙事发动机/场景 → 文学写作
                                                      ↓
用户收到终稿 ← 发布版式/视觉策略 ← 受约束的最小改稿 ← 独立审校 ← 事实门禁
                                                   ↓
                                                数据复盘（可选）
```

## 不变式

1. 不因评审分数高而覆盖事实错误，不能用含糊的诗意语句伪装引文。
2. 用户批准的“只审不改”是不可突破的范围限制；改动仅在授权的文本范围内。
3. 单图是独立模式，不强推多图或未请求的视频。
4. 静态验证、事实核查、模型实际生成、发布结果四种证据严格区分。
5. 不纳入账户后台数据、私人通讯、未授权原文或第三方图片作为公开训练案例。

## 扩展策略

新叙事方法加到对应参考文档，不增长入口到模型不易加载的长度。可选平台指南、新审稿测试必须有真实失败样例与期望结果。脚本仅用 Python 标准库，不需要联网、API Key、遥测。
